鏡 KAGAMI — HTMLを画像へ

このドキュメントはレンダリング検証用のサンプルです。日本語テキスト、グリッドレイアウト、 グラデーション、ボーダー、タイポグラフィの各要素を含みます。Satoru エンジンは Skia 上で CSS レイアウトを計算し、ベクトル経由でラスター画像を生成します。

Vector Pass

レイアウト結果は SVG ベクトルとして出力され、任意のコーデックへ単一パスでラスター化されます。

Parallel Encode

エンコーダ候補はワーカープールへ分散され、最小バイトを達成した候補が採用されます。

Layout Reuse

解析済みのドキュメントインスタンスを保持し、幅変更時はレイアウトのみを再計算します。
